# 个人知识库

[打开个人知识库](https://greenmashimaro.github.io/personal-notes/)

在 GitHub 网页打开 `notes/`，选择 **Add file → Upload files** 上传 `.md` 或 `.html`。

文件名使用 `YYYY-MM-DD 标题`，日期和标题之间留一个空格。例如 `2026-11-13 Electron 调研报告示例.html` 或 `2026-11-12 Electron IPC 笔记.md`。

提交到 `main` 后，GitHub Pages 会自动更新首页。列表按文件名前缀日期从新到旧排列。
