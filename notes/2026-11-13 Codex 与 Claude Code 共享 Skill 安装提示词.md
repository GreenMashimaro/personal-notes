# Codex 与 Claude Code 共享 Skill 安装提示词

以后安装新 Skill 时，复制下面的提示词，将「技能链接或仓库地址」替换为实际地址。

```text
请安装这个 Skill：<技能链接或仓库地址>，要求 Codex 和 Claude Code 都能使用，并遵循我现有的统一管理方式：

- 将技能原件放在 ~/.agents/skills/<技能名>/，供 Codex 读取。
- 在 ~/.claude/skills/<技能名> 建立指向原件的软链接，两边共用同一份文件。
- 安装前检查兼容性、依赖和同名技能。已有相同技能则复用，内容不同则保留现有版本并说明差异。
- 如果使用安装器，优先使用其支持的共享安装方式，保留来源和更新记录。
- 如果包含工具专属功能或属于插件，说明适合的安装方式。
- 安装后检查软链接，并尽可能验证两个工具都能发现该技能。说明尚未验证的部分，以及是否需要重启。

请直接执行安装，仅处理本次指定的技能。
```
